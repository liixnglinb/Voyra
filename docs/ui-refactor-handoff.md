# Voyra UI 重构交付说明

> **⚠ 历史记录（2026-10-03 停用）**：本文描述的「软件共用视觉基础层」机制已于 2026-10-03 起整体停用——五款软件各自独立维护 UI，不再有共享层；`design-system/`（software-base.css、legacy-dialogs.js、adapters/*）与 `scripts/sync-software-ui.mjs` 已删除，`npm run ui:sync` 已移除。Token Monitor 更早在 v1.9.13 就自带了 `tokens.css` 单一源。本文仅作历史记录，**不要按本文去操作已删除的文件**；现行规则见维护文档 §2.7。

基线版本：1.0 · 2026-10-02。

后续更新：2026-10-03 已完成第二轮主要页面与异常路径细化。最终 20 项浏览器回归通过；新增复测入口为 npm run test:software-ui。详情及已验证/未验证边界见 ui-refactor-phase2.md。下文「本轮」指第一轮基础层交付，不覆盖后续第二轮记录。

## 已落地的代码

- 新增 `#/design-system`：平台通用规范 39 条，五款软件各 14 条产品适配，共 109 条；覆盖七个维度，附 6 类组件 × 8 种状态矩阵和每款软件的边界验收清单。
- 规范页支持对象/维度切换、跨维度检索、Markdown 导出、剪贴板复制及失败回退。组件实验区展示深浅色、默认/加载/禁用/成功/失败和安全确认示例。
- 首页 11 张产品卡、7 张应用卡使用新的统一展示组件。Skills、关于我、交流卡统一材质、圆角、间距和反馈；原 Hero 和产品入口保留。
- 展示卡使用分层入场、精细指针光斑、轻倾斜；屏外与隐藏页停止演示轮播；系统减少动态效果下禁用倾斜、循环和平滑滚动。
- 七个下载页接入共享卡片材质、主题适配及动效。版本脚本、资产链接和下载选择逻辑未更改。开发/预览服务器补齐目录首页行为。
- 五款软件的实际源码已接入共享视觉基础层，并分别映射原有设计变量。AI 轨迹和织流使用墨色/暖金；Token 保留深色计量与图表语义色；磁盘保留风险色和紫色识别；签到保留暖橙与运行状态。
- Token 旧导航补充键盘 Enter/Space 与当前位置语义；部分报表辅助文字的对比度提高。磁盘侧栏和正文尺寸对齐基线，紧凑窗口折叠导航。原生标题栏为尺寸例外，未强行扩大至普通表单尺寸。
- 联系方式复制反馈现在基于实际结果，并提供失败提示和焦点恢复。

## 规范与实现必须区分

这不是“109 条业务规则已经全部实现”的宣称。产品规则是逐页改造与验收的目标契约。

五款软件本轮完成的是共享视觉/组件状态基础层接入和局部交互修正；原有页面与业务结构继续保留。没有把所有页面的信息架构、全部异常状态和每项无障碍要求重新实现。后续应按软件逐页对照规范落实，而不能仅以样式同步成功替代业务验收。

## 维护与归属

- 主基线：`public/design-system/voyra-foundation.css`。
- 共用软件层：`design-system/software-base.css`。
- 产品映射：`design-system/adapters/`。
- 同步工具：`scripts/sync-software-ui.mjs`；只接受显式的绝对目录，不扫描桌面、凭据或私人文档。
- 软件项目中新增 `voyra-foundation.css`、`voyra-software-base.css`、`voyra-ui.css`。签到采用生成的 TypeScript CSS 字符串，避免破坏离线/PWA 与 CSP 路径。
- 规范数据：`src/data/software-ui-spec.js`、`src/data/software-ui-products.js`；Markdown 由这些公共数据机械导出。
- `UIKit.jsx` 和 `uikit-components.js` 的独立仓库源文件没有修改，仍与主仓库一致。没有触发产品自动同步覆盖。
- 磁盘清理和签到工具中原有未提交修改保留；未提交无关备份、构建产物或私人说明文档。

常用命令：

```text
npm run build
npm run test:ui
npm run ui:spec
npm run ui:spec:check
npm run ui:sync -- chronicle=<绝对目录> token=<绝对目录> disk=<绝对目录> checkin=<绝对目录> jacquard=<绝对目录>
```

同步命令默认只校验；明确添加 `--write` 才覆盖生成的样式副本。手工修改软件副本会在下次同步时被覆盖，应修改主基线/适配层。
