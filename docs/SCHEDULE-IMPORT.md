# 课表分享与教务导入修复

本轮在已上线的手机弹窗基础上调整功能菜单宽度、左右内边距，并为弹窗标题留出可收缩的空间，关闭按钮固定在右边的 44px 触控区，标题长短和课程数量不再影响其横向位置。

## 分享

- 分享页签不生成请求。只有点击生成按钮才发送一次 POST，立即显示加载状态并阻止重复点击。同一份内容在当前页面复用已生成链接；8 秒超时后给出重试提示。
- 页面只展示 `/s/<7位ID>` 短链接，不再显示长口令，也不会在短链服务异常时把长链接作为结果展示。复制由单独的点击操作完成，适配手机剪贴板权限。
- 服务端保留原有 D1 `share_links` 表。生成采用一条 `INSERT OR IGNORE ... RETURNING id` 处理插入和 ID 冲突，过期清理放到 `waitUntil`，每次最多 100 行。接口请求体上限 44 KB，编码上限 40 KB。
- `/s/<id>` 只跳转到带 `shareId` 的短参数地址；前端通过 `GET /share?id=<id>` 读取内容。GET 和跳转均检查 180 天期限。旧数据库记录、VOYRA1/2 口令、旧长链接继续兼容；新编码 VOYRA3 保留分隔符、备注、全部时段和作息设置。
- 接收者先预览，点击「下载并保存」后自动合并进自己的课表。未登录时打开站内登录，登录完成后自动继续保存，无需第二次确认。每个新增课程分配接收者自己的 ID，使用接收者的用户存储键和云端账号，不建立指向分享者课表的可编辑引用。
- 重复下载按课程实际内容去重，已有课表和已有设置继续保留；空课表才采用分享中的开学日期与作息。双方随后可独立编辑。

## 数据保留

继续使用 `ClassScheduleData_<uid>` 和 `schedule-classes-v1`。保存前保留原始本机 JSON 到 `.original-v2`，第一次读取的非空云端记录另存 `.cloud-original-v2`；课表备份导出包含这两份原始数据。数据损坏或本机存储失败时不会提示保存成功，也不会覆盖原文。

同步采用按课程 ID 的合并和可选 `_scheduleSync` 编辑/删除时间戳；空云端与迟到的读取不能抹掉新导入。2026-10-25 起，分页读取当前账号同一同步键的全部版本，每个浏览器只写自己带设备标记的云端行，兼容并保留历史重复行，避免两个设备同时覆盖同一行。原始云端版本保留在本机 `.cloud-rows-v1`（最近 8 份）并随备份导出。写入串行且检查当前账号和 SDK 登录凭据；云端响应异常、本机损坏、请求超时或存储失败时停止覆盖并提示。

返回页面、恢复网络、同源课表变更以及前台每 30 秒自动读取更新；隐藏页面不轮询。常规同步在后台运行，不显示同步状态条和手动同步按钮；仅失败时显示重试或登录提示。登录失效提示重新登录，同账号登录后立即继续上传本机记录。退出登录仅移除登录凭据，不调用 SDK 中会清空所有本机存储的 `logout()`；注册后显式保存 SDK 会话，保证私有 ACL 请求携带有效登录凭据。不同网站的本机存储仍各自独立：旧的未上传数据必须在原设备、原网址打开新版页面才能合并上传。底层不是服务端事务，不声称跨设备强一致性；并发修改按已有课程时间戳合并。

## 教务导入

默认提供湖南人文科技学院自动导入：安装浏览器助手 → 设备上探测校内地址（5.5 秒超时）→ 不通则打开学校 VPN → 用户在学校页完成登录 → 悬浮助手检测课表并逐周读取 → 返回本站预览 → 确认后合并进当前账号。能读取有效教务登录页就保留内网入口，不因用户登录耗时而切换网络。校外入口已于 2026-10-23 验证返回学校登录页；真实学生账号、校园设备的浏览器扩展权限与登录后课表 DOM 仍需在相应环境实测。

普通网页受同源、混合内容和窗口隔离限制，不能直接读取学校登录页。`public/jsxsd-import.user.js` 是安装到 Tampermonkey 的助手，权限仅用于本站、两个学校主机和学校重定向连接。首次设置页给出安装入口；微信内置及其他不支持扩展的手机浏览器保留手动复制、Excel、截图导入，也可在电脑导入后登录同账号同步到手机。没有安装助手时不显示虚假自动进度。

助手不读取密码字段、不代理认证、不提交登录表单、不自动执行保存/删除等教务操作。默认只导航已匹配的个人课表链接；有同源 frame 时会继续查找其中的课表，跨源嵌入页提示用户在新窗口打开。周次读取复用原查询表单的学期、隐藏字段和查询地址，只向当前学校域发请求；限制到已识别的课表查询路径。每次返回必须包含完整课表及对应周次选择值；失败时不给出完整结果，已完成周次保留在当前学校页内存，点重新检测可继续。完整学期表若已包含明确周次，可以直接读取，不猜测缺失周次。

结果通过扩展本机存储传递，不使用 `window.opener`、长链接、公开短链数据库或学校密码。任务随机 128 位 ID、限定返回本站来源、1 小时时效，并在网站绑定发起账号；跨账号、未知和过期任务不进入预览。只有用户核对并保存后才合并，随后清除助手中的课表结果。原有课表键、同步、备份与分享数据格式继续兼容。

手动路径仍提供三个步骤：选择学校及校园网/校外入口 → 在学校网页登录、选择学期并复制完整表格 → 回站内识别、预览并保存。

解析同时支持剪贴板 HTML 表格（含合并单元格）、带引号的多行 TSV、周一/星期一表头、前置时间列、中文大节、教师/教室及真实周次。零散周次按实际周保留；单双周使用页面接受的 `odd/even` 值。权限拒绝、空剪贴板、无课程和学校入口打不开时都有明确的手动粘贴或 Excel/图片替代路径。

校内地址沿用学校公开的[教务管理系统说明](https://www.huhst.edu.cn/chxy/info/1156/3911.htm)中的 `/jsxsd/`；校外使用原有 VPN 域名的根入口，取消固定的历史 CAS 跳转串。校内网络、实际学期页面和真实学生账号登录仍需在相应校园环境验证，测试不会收集账号密码。

## 验证

- `npm run test:schedule:import:data`：编码兼容、账号隔离、幂等合并、旧数据保留、延迟同步、TSV/周次解析和真实 SQLite SQL/短链接口。
- `npm run test:schedule:import:ui`：先运行 `npm run build` 和 `npx wrangler pages dev dist --ip 127.0.0.1 --port 8789 --persist-to output/playwright/schedule-import-v2/d1`。使用真实本地 Workers/D1 验证生成、短链跳转、已登录下载、模拟登录后自动保存、重复下载、教务导入和手机布局。
- `npm run test:schedule`：保留原来的全部课表弹窗回归。
- `npm run test:schedule:sync:data`：多设备并发、旧重复行、分页、错误响应、本机损坏、账号切换和只读刷新。
- `npm run test:schedule:sync:ui`：先构建，再用两个独立网站来源、真实打包页面及真实 Bmob SDK，拦截 REST 到共享假后端，验证手机/电脑双向同步、失败重试、同账号重新登录、注册凭据与退出/过期保留本机数据；不替换页面 API、不写真实账号。
- `npm run build:education`：使用共享解析、校验模块打包独立用户脚本；dev/build 自动生成，`node build-tools/build-education-helper.mjs --check` 可检查产物一致性。
- `npm run test:education:data`：真实网络失败/超时/登录可达判定、取消、精确周次合并、任务来源和有效期。
- `npm run test:education:ui`：生产 CSP/COOP 下的真实 Chrome 与两个模拟学校来源；GM 授权 API 用本机测试适配模拟，验证登录不被打断、逐周失败及续读、完整学期、当前账号确认保存、跨账号阻断、刷新恢复、5 个尺寸安装与手动入口。并未用真实学生账号登录学校。
- 所有测试账号与课表均为独立浏览器上下文中的假数据，云端账号写入被模拟，不接触真实用户课表。
