# 课程表功能弹窗 · 手机优先

范围为日程中心「课程表 → 功能」的菜单、周次、作息时间、课程明细、导入、添加与清空弹窗。

## 布局与交互

- 手机保留 12px 水平边距，正文滚动，标题与底部动作固定在弹窗内。尺寸跟随 Visual Viewport 更新，适配浏览器工具栏与输入键盘造成的可用高度变化。
- 周次以 5 列、4 行展示；选中即沿用现有逻辑保存并按日期自动推进，支持方向键。
- 作息以节次、上课和下课三列对齐。时间编辑器在对应行下方展开，滚轮每项 44px，分钟按 5 分钟递增；短横屏使用横向编辑器。
- 添加课程顶部始终展示名称和教室，老师、学分、备注、配色默认折叠。上课安排以星期、节次、时间、周次摘要展示，点「调整」展开；星期用 4+3 个触控按钮，节次按两列排列。字段 48px，时段按钮至少 44px，底部保存动作固定。桌面信息与时段双栏，手机单栏。
- 双击空白格带入该格星期、节次和当前查看周，默认单节课，仅该周上一次；相邻周不会显示。菜单手动添加仍支持连续多周。多时段、单双周、自定义时间与颜色功能保留；保存校验名称、周次先后和自定义时间，写入失败保留草稿。
- 常规同步状态与手动同步按钮移除，返回页面、恢复网络及前台定时同步照常运行；同步失败或需要登录时才提供处理提示。
- 导入保留 Excel、教务、截图、分享和备份；确认导入放在固定页脚。课程明细以独立条目显示，并提供编辑、删除入口。
- 功能菜单按实际按钮位置计算可用宽高，短屏可在菜单内滚动。弹窗支持焦点约束、Esc 和关闭后焦点返回。
- 添加/导入在未登录时保留草稿并打开现有登录界面；添加与编辑成功后关闭弹窗。

## 维护

- `src/pages/ClassSchedule.jsx`：表单、周次、行内时间编辑及课程交互；保留既有数据格式和同步方式。
- `src/styles/schedule-dialogs.css`：仅作用于 `.cs-dialog` 及功能菜单。日历与作业共用的基础 `MobileBox` 保留原样式。
- `src/pages/ScheduleHub.jsx`：功能菜单的说明与边界适配。

## 验证

运行 `npm run build` 后运行 `npm run test:schedule`，并保留原有 `npm run test:ui`。

验证使用临时浏览器中的示例账号和本地数据，云端方法被模拟，外部请求被阻止；不会操作真实账号或真实课表。覆盖 320×568、360×740、390×844、430×932、844×390、768×1024、1440×1000 的布局检查，新增快速添加的折叠/展开、指定周保存与相邻周隐藏、名称与教室直接可见、选填资料折叠，并验证选周保存、时间选择与非法区间、恢复默认、周四课程、自定义时间、添加/编辑、备份导入、焦点与未登录草稿。可用高度缩小通过浏览器视口模拟，等待 Visual Viewport 更新后检查，实际 iOS/Android 输入法仍应在设备上复查。
