# Voyra 软件 UI 规范

版本：1.0 · 2026-10-02

这是目标设计与验收契约，不代表所有业务交互已实现；预览不是实时数据。

## 平台通用规范

### 信息架构与布局

#### 导航层级
一级入口不超过 8 个；业务导航在侧栏，设置固定在底部；当前位置使用文字、背景与 aria-current。
验收：任一业务页最多 2 次操作返回主任务。

#### 桌面外壳
侧栏目标 240px，折叠 64px；顶栏 64px；内容边距 24px，最大阅读宽度 1440px。窗口拖拽区与按钮分离。
验收：1280×800 下主操作可见，弹窗不遮窗控。

#### 响应式
≥1280 多列；960–1279 紧凑侧栏；768–959 可折叠导航；≤767 单列、触摸目标 44px；表格仅在自身容器横滚。
验收：320 / 390 / 768 / 1280 / 1440px 无整页横向溢出。

#### 信息顺序
页标题＋范围/更新时间→核心指标→主任务→明细→帮助；每区块只有一个主动作，危险动作单独分区。
验收：首屏可判断当前状态与下一步。

#### 滚动与定位
应用壳固定，主内容独立滚动；筛选切换保留条件，返回列表恢复位置；锚点避让头部 88px。
验收：返回、刷新与深链不丢失页及筛选。

### 视觉设计

#### 共享颜色
暖白画布 #F6F5F1、白面板 #FFFFFF、墨色 #20211F、正文 #454740、辅助 #696B62；正文金 #80651C 配浅金 #FFE08A。装饰金 #A48830 不用于小正文。
验收：最终组合色可读，主题覆盖面板/输入/浮层。

#### 深色层级
画布 #191A18、面板 #232420、内层 #2C2D28、正文 #EEEEE7、辅助 #A7A99E；不用纯黑配纯白长正文。
验收：阴影消失时仍有表面层级与边框。

#### 字体与数字
系统字体离线可用；正文 14px/1.65，辅助 12px/1.5，区块 20px/1.3，主指标 32px/1.1；字重 400/500/600/700；数字 tabular-nums。
验收：中文、英文模型名与金额不重叠。

#### 间距与圆角
间距 4/8/12/16/20/24/32/40px；控件圆角 8px、业务面板 12px、网站展示卡 20px、胶囊 999px。
验收：同一层级不用随机间距与圆角。

#### 语义色
成功绿、提醒琥珀、失败红、信息蓝；必须配图标或文字；产品强调色只用于选中、重点和图表，不覆盖危险色。
验收：灰度下仍能区分状态。

#### 材质与密度
业务面板 1px 边框＋低扩散阴影；展示卡可用局部光斑；业务页不使用大面积玻璃、持续闪烁或无意义渐变。
验收：报表保持数据密度，不变成营销卡墙。

### 组件与尺寸

#### 按钮
常规 40px、密集工具栏 32px、触摸 44px；横向内边距 16px、图标 16px、间距 8px。主按钮墨底白字，次按钮描边，危险按钮红色。
验收：所有按钮具名；仅图标按钮有 aria-label。

#### 输入与筛选
输入高 40px，标签常驻；错误紧邻字段并关联 aria-describedby；搜索去抖 250ms、Enter 立即执行。
验收：失败保留输入，清空有明确入口。

#### 导航与分段
导航行 ≥40px；显示选中、焦点与禁用原因；真正标签页使用 tablist/tab/tabpanel 及方向键。
验收：键盘可切换并读出当前位置。

#### 指标与图表
标题→数值→口径→更新时间；包含单位、范围与缺失说明；图表有文字或表格替代，未知值不填 0。
验收：图表、总量和明细统计口径一致。

#### 表格与列表
表头 36px、行 ≥44px；数值右对齐、文字左对齐；排序标注 aria-sort；长路径可复制；大列表分批加载。
验收：1000 行不卡；选择不误触打开。

#### 弹窗与抽屉
确认框 440–560px，复杂编辑 ≤720px；max-height:80dvh，正文滚动、动作固定；标题具名、取消在左。
验收：Esc 关闭、焦点锁定、关闭恢复焦点。

#### 通知与帮助
普通成功提示 4s，错误保留至关闭；重要失败不能只藏在 Toast；帮助解释原因、后果与修复方式。
验收：复制失败有反馈，读屏不过量播报。

### 组件状态

#### 默认 / 悬停 / 按压
默认体现可操作性；hover 改表面/边框，active 最多位移 1px；业务面板不整体漂移；触屏主动作不依赖 hover。
验收：禁用没有悬停或按压反馈。

#### 键盘焦点
focus-visible 使用 2px 高对比边框、偏移 3px；不能只用阴影或去除 outline；焦点与选中可同时分辨。
验收：Tab 顺序正确且不被吸顶头部遮挡。

#### 加载 / 处理中
保留按钮宽度、显示「处理中…」、阻止重复提交；≥400ms 等尺寸骨架；长任务展示阶段、进度与取消边界。
验收：加载不清空整页，失败可重试。

#### 禁用 / 只读
保留标签及原因；opacity 0.55 只用于非关键文字；只读可选择复制；危险主动作无选择时禁用并解释。
验收：disabled 与 readonly 语义不同。

#### 成功 / 失败 / 部分成功
成功说明对象和结果；失败说明原因、影响与恢复动作；部分成功列出数量，仅重试失败项。
验收：不重复执行已成功的破坏性操作。

#### 空 / 无结果 / 无权限
首次空态提供开始入口，筛选空态提供清除条件，权限拒绝说明所需权限；断网仅降级受影响功能。
验收：未知/读取失败不显示成正常 0。

### 交互与动效

#### 节奏
hover/focus 120ms、组件切换 200ms、入场 360ms；缓动 cubic-bezier(.2,.8,.2,1)；错峰 40ms，总错峰不超过 200ms。
验收：连切 10 次不积累动画或监听。

#### 网站展示卡
入场轻移 12px；精细指针光斑＋≤±2deg 倾斜，图层深度 8px；滚动外层、入场内层、hover 表面分离。
验收：不覆盖已有滚动 transform。

#### 性能
连续动画只用 transform/opacity；pointermove 合并到 requestAnimationFrame，不每帧 setState；屏外/隐藏页暂停。
验收：无空闲动画帧，不全局 will-change。

#### 状态反馈
不伪造百分比；真实完成才成功；取消显示真实结果；错误和危险反馈不受动画延迟。
验收：动效表达变化，不掩盖结果。

#### 减少动态效果
prefers-reduced-motion 下禁用倾斜、视差、滚动翻转、循环和平滑滚动，保留静态边框和状态反馈。
验收：运行中切换偏好即时生效。

### 内容与边界情况

#### 文案
使用动词＋对象：「扫描磁盘」「导出报告」「停止监听」；错误写原因＋影响＋下一步，不仅写「失败」。
验收：关键反馈不只有技术码或图标。

#### 格式
日期/时区明确；Token ≥1M 可用 M，详情有精确值；金额注明币种/估算；空间用 GiB/MiB 并解释单位。
验收：舍入不改原值，排序按原值。

#### 长内容
标题两行，路径/哈希可断词；列表省略但提供完整详情/复制；Toast 限宽，长正文可滚动。
验收：200 字标题/256 字路径/空值不破坏布局。

#### 本地与离线
本地可读时主流程可用，云不可用只降级对应功能；无真实数据显示空态，不伪装演示统计。
验收：离线重开/读取异常有恢复路径。

#### 风险与恢复
删除、覆盖、清空、导入替换预览对象/数量/范围/不可恢复性；默认安全焦点；任务不无提示丢弃。
验收：不移除既有权限、确认或隐私约束。

### 可用性与无障碍

#### 可感知
正文目标 ≥4.5:1，大字 ≥3:1，边界/焦点 ≥3:1；不只靠颜色；装饰 aria-hidden，内容图有 alt。
验收：验证最终组合色，不只检查 token。

#### 可操作
全功能支持键盘；目标至少 24×24px，项目标准桌面 40px/触摸 44px；间距 ≥8px；快捷键不抢输入。
验收：无键盘陷阱。

#### 可理解
标签/帮助/错误关联字段；必填明确；提交失败聚焦首个错误且保留输入；危险动作再次确认。
验收：读屏可理解名称、角色、状态。

#### 焦点与通知
弹窗聚焦标题/安全操作，关闭恢复；aria-live=polite 用于结果，alert 仅紧急失败，进度播报节流。
验收：验证开关弹窗及切换页的焦点。

#### 缩放与设备
200% 缩放可用，400% 保留主流程；高对比模式有边框；鼠标/键盘/触摸可用，在线页不锁方向。
验收：窄屏不隐藏核心状态/主操作。

## AI 轨迹 · AI Chronicle

核心任务：看清今天做了什么，找到会话与产出，继续上次的工作。
平台：Electron / React / TypeScript
导航：今日工作台 → 会话档案 → 时间轴 → 项目集 → 成果集 → 分析 → 接入中心 → 设置中心

### 信息架构与布局

#### 工作台顺序
日期/采集状态→今日结论→关键任务与产出→续接；耗时与 Token 为辅助，不把记录工具变成计费报表。
验收：首屏看见今天结论和续接入口。

#### 档案与详情
会话保留来源/模型/项目/日期筛选；项目串联会话与成果；时间轴按本地日期分组；≤959px 详情变抽屉/单页。
验收：项目→会话→返回不丢筛选。

### 视觉设计

#### 记录气质
墨色＋银白：暗色档为纯黑白灰（品牌色银白、语义色只用明度区分），浅色档保留暖金；摘要 20px、任务 14px、时间/来源 12px；来源轻标签而非整卡染色。
验收：浅/深模式均保留阅读层次，暗色档无彩色残留。

#### 成果层级
时间等宽，文件类型用小图标；收藏与完成用明度差＋图标区分，暗色档不引入彩色；路径从标题中分离。
验收：收藏与完成可区分。

### 组件与尺寸

#### 业务组件
日期选择、今日摘要、任务行、来源标签、会话筛选、项目卡、产出文件行、采集健康卡。任务行 ≥44px。
验收：指标注明范围和更新时间。

#### 检索与续接
Ctrl/Cmd+K 命令面板，/ 聚焦搜索；结果分项目/会话/成果；续接显示目标工具与目录。
验收：输入中不抢快捷键。

### 组件状态

#### 采集状态
未接入/扫描中/正常/不可读/部分失败分开；更新时间、成功数及跳过数同时可见。
验收：单源失败不清空其他来源。

#### 摘要与文件
摘要待生成/生成中/失败/已生成；文件存在/已移动/不可访问分别反馈，打开失败可复制路径。
验收：不静默掩盖文件丢失。

### 交互与动效

#### 阅读稳定
会话切换淡入 200ms；任务完成只变图标；新采集不抢滚动，时间轴提供「回到今天」。
验收：长会话阅读不被刷新打断。

#### 低打扰
新内容标记数量，不持续弹出；复制反馈约 4s；屏外列表停止装饰动画。
验收：隐藏页面无无意义动画。

### 内容与边界情况

#### 无数据与跨日
无会话引导接入，无筛选结果提供清除；未知耗时与 0 分开；跨午夜会话说明日期归属。
验收：不虚构示例为真实结论。

#### 隐私与长内容
日志默认本地；导出说明含原文/路径；200 字标题和超长目录可复制；UI 不回显凭据。
验收：导出范围可审阅。

### 可用性与无障碍

#### 档案可读
会话用可聚焦链接/按钮；时间轴给出时间、来源、任务名；收藏播报按下状态。
验收：不只靠颜色判断状态。

#### 命令面板
方向键选择、Enter 打开、Esc 关闭并恢复焦点；深色辅助文字保持可读。
验收：键盘完成搜索→进入→返回。

### 重点验收场景
- 首次无来源
- 多源部分失败
- 200 字任务标题
- 已移动文件
- 跨日会话
- 深浅主题与缩放

## Token 统计 · Token Monitor

核心任务：以一致口径查看本机 AI 用量，理解成本、缓存及被排除的数据源。
平台：FastAPI / HTML / JavaScript
导航：用量总览 → 模型用量 → 数据源筛选 → 通用偏好 → 扫描与缓存 → 关于

### 信息架构与布局

#### 计量顺序
范围/扫描时间→金额主指标→Token/请求/缓存→趋势→模型/每日明细；数据源筛选在侧栏。
验收：总览和模型页共享筛选。

#### 报表密度
长表格行内展开，KPI 窄屏两列/单列，明细独立横滚；设置按常规/扫描/关于分组。
验收：精确数值和口径不被隐藏。

### 视觉设计

#### 深色计量台
默认深色，与共享深色表面统一；Token 蓝、成本琥珀、缓存青；指标在各视图同色。
验收：图表不全部染金，来源可辨。

#### 数值层级
金额 32px、辅助指标 24px、明细 14px；币种/估算常驻，数字等宽。
验收：0、未知与估算可辨。

### 组件与尺寸

#### 业务组件
范围筛选、金额卡、Token 卡、缓存徽章、趋势图、模型行、来源健康、每日明细。
验收：指标有定义和精确值。

#### 来源解释
参与汇总与聚合器/归档/价格源分区；跳过来源展示原因，默认不计入总量。
验收：UI 不改变汇总集合。

### 组件状态

#### 扫描生命周期
待扫描→扫描中→完成/部分跳过/失败；保留上次有效数据并标记刷新中；不伪造百分比。
验收：重复刷新不重叠扫描。

#### 定价与缓存
未知价格显示「未定价」，不能用 ¥0；缓存不存在/命中/失效分别说明；预算源注明跳过。
验收：数量准确与成本可算分开。

### 交互与动效

#### 稳定数据
刷新不重复数字计数；图表 200ms 更新，提示框不弹性追逐；筛选不重建整页。
验收：金额可立即读取。

#### 材质克制
保留局部表面高光，移除持续极光/呼吸；处理中用状态文本，不以无限闪烁代替。
验收：静止报表没有空闲动画。

### 内容与边界情况

#### 统计口径
输入/输出/缓存/总量分开，时区/价格日期明确；模型归一化不在 UI 重算；重复源不重复计量。
验收：总量与明细求和一致。

#### 损坏与未知
日志损坏/无权限/超大/未知模型说明原因和影响；缺失价格提供补充入口；亿级数字不溢出。
验收：不把不可计算显示成免费。

### 可用性与无障碍

#### 数据替代
图表有文本/表格；精确值可键盘聚焦；列排序 aria-sort，筛选标记选中。
验收：不用鼠标也能读明细。

#### 刷新播报
完成只播报总体结果和跳过数，不按每行播报；辅助文字保持深色可读。
验收：可理解范围和更新时间。

### 重点验收场景
- 空日志
- 跳过来源
- 未知模型价格
- 1000 行明细
- 超大数值
- 键盘筛选与排序

## 磁盘清理助手 · Disk Cleanup Assistant

核心任务：先理解空间占用和文件风险，再由用户确认清理对象。
平台：Electron / React / FastAPI
导航：概览 → 清理 → 软件 → 设置

### 信息架构与布局

#### 安全流程
选择磁盘/目录→扫描→分类/分析→选择→清理预览→确认→结果；扫描和删除是两个动作。
验收：没有明确确认不触发删除。

#### 结果外壳
左树右清单/说明；顶部路径/容量/阶段，底部选择数/清理动作；窄屏详情抽屉。
验收：滚动后仍知道操作范围。

### 视觉设计

#### 风险优先
中性色＋低饱和紫为扫描/选中，安全绿/谨慎琥珀/危险红；高风险不渲染为推荐。
验收：品牌色不覆盖风险色。

#### 目录密度
路径等宽 12px，说明 14px，容量右对齐；类型和风险配图标/文字。
验收：长路径不挤掉选择和容量。

### 组件与尺寸

#### 业务组件
路径选择、阶段进度、容量条、分类、目录树、三态选择、风险徽章、目录百科、清理预览/结果。
验收：部分选择区别全选。

#### 危险确认
显示完整根路径、项数、容量、处理方式和不可恢复提醒；取消默认聚焦，确认具名。
验收：保留二次确认及后端保护。

### 组件状态

#### 扫描阶段
准备/枚举/分析/完成/取消/部分不可读；保留已获结果，取消不伪称全量完成。
验收：进度不是无限转圈。

#### 清理结果
无选择禁用并解释；执行中、部分成功、失败清单与仅重试失败项；重扫清除旧危险选择。
验收：文件占用/权限失败明确。

### 交互与动效

#### 大量文件
目录展开 200ms，选择立即反馈；扫描分批稳定更新，不对每个文件做入场。
验收：大结果不掉帧。

#### 危险区静态
删除按钮/确认/风险警告不漂移不脉冲；完成淡入，不自动关闭失败清单。
验收：错误可持续阅读。

### 内容与边界情况

#### 文件边界
系统保护、符号链接、无权限、被占用、已消失、空目录和大文件分别解释；建议不承诺绝对安全。
验收：不绕过后端路径校验。

#### 空间口径
注明逻辑/实际占用及 GiB/MiB；实际释放以真实结果为准；0B/未知/未扫分开。
验收：选择量不冒充释放量。

### 可用性与无障碍

#### 树与选择
节点展开可读，键盘可选择，三态选择播报 mixed；风险不只靠色。
验收：键盘能进入预览并取消。

#### 安全焦点
确认焦点锁定、Esc 取消、关闭回触发；后台扫描不抢焦点。
验收：高对比危险边框可见。

### 重点验收场景
- 无选择
- 无权限
- 保护路径
- 256 字路径
- 扫描取消
- 清理部分成功与安全取消

## 学习通自动签到 · Superstar Check-in

核心任务：知道监听是否正常，及时发现需要人工完成的签到活动。

导航：总览 → 课程 → 课表 → 历史记录 → 日志 → 设置

### 信息架构与布局

#### 状态优先
账号有效性/监听状态→待处理→课程健康→记录趋势；人工事项不藏在成功计数下。
验收：首屏能确认是否在监听。

#### 多端设置
桌面侧栏/手机折叠导航；控制与记录分区；账号/监听/通知/手机连接分组；保存范围清楚。
验收：手机不遮二维码与待处理动作。

### 视觉设计

#### 暖色状态
暖白＋低饱和橙；正常绿/待处理琥珀/失败红/暂停灰；状态文字常驻。
验收：暂停和失败不同。

#### 待处理识别
待处理有边框/图标；品牌橙不代替风险；统一墨底白字主按钮。
验收：不识色也能找到人工事项。

### 组件与尺寸

#### 业务组件
监听条、账号卡、课程开关、待处理卡、二维码上传、结果行、时段表、通知诊断、连接说明。
验收：课程健康和成功率分开。

#### 服务确认
开关具名、切换中锁定，服务确认才更新；删除账号与停止监听分开。
验收：界面不假称操作已成功。

### 组件状态

#### 连接与账号
未配置/登录中/有效/过期/断网/需人工验证各有反馈，过期保留设置与记录。
验收：网络错误不冒充密码错误。

#### 活动生命周期
发现→处理中→完成/需人工/超时/失败；手势/拍照明确需 App，重试遵守冷却。
验收：不宣传全部自动或鼓励连续请求。

### 交互与动效

#### 常驻低扰
状态轻淡入，记录不每秒弹出；停监听先反馈处理中，服务确认后暂停；刷新不重排阅读中的记录。
验收：状态反馈准确稳定。

#### 手机上传
静态占位/明确按钮，结果保留不自动收起；隐藏页暂停装饰动画。
验收：低性能设备可手动处理。

### 内容与边界情况

#### 能力范围
普通/位置/二维码与手势/拍照人工区分；提醒不保证成功，仅展示用户有权访问课程。
验收：失败可走官方 App 人工路径。

#### 隐私与错误
结课/重复/过期/二维码无效/跨网限制/推送不可用有明确说明；密码/token 遮罩，导出提示范围。
验收：截图/日志不暴露凭据。

### 可用性与无障碍

#### 可读状态
开关有 switch/checkbox 语义及课程名；适度播报待处理数；上传支持键盘，二维码有文字说明。
验收：不只有一张二维码图片。

#### 触摸布局
目标 44px，键盘不挡保存，课程长名折行；帮助解释恢复步骤。
验收：缩放后仍能暂停监听。

- 会话过期
- 需人工活动
- 二维码失败
- 断网/通知不可用
- 手机与键盘操作

## 织流 · Jacquard

核心任务：编辑本地智能体流程，了解每步进度，审阅真实产物后继续工作。
平台：pywebview / FastAPI / HTML / JavaScript
导航：新建任务 → 搜索 → 工作流 → 技能库 → 运行记录 → 设置

### 信息架构与布局

#### 创作骨架
左任务/运行，中输入/流程，右按需产物；引擎/模型/目录/权限在启动前清楚显示。
验收：用户知道任务在哪运行。

#### 编排与窗口
节点按顺序；配置生效时点明确，运行保留快照；小窗口产物切换，发送/停止常驻。
验收：1024×768 可停止任务。

### 视觉设计

#### 工作台气质
墨色动作＋暖金重点，日志/代码等宽；节点用状态，不彩虹染色；产物用共享中性色。
验收：内容重于装饰。

#### 权限层级
运行蓝/完成绿/失败红/授权琥珀；权限级别有文字，不只一把锁。
验收：授权不冒充成功。

### 组件与尺寸

#### 业务组件
输入台、流程节点、模型、工作目录、权限、运行条、日志、产物行、技能编辑、更新提示。
验收：输入/运行/产物一致关联。

#### 执行动作
启动显示流程与环境；停止说明部分产物；重跑标明原快照或当前配置。
验收：不绕过权限检查点。

### 组件状态

#### 运行状态机
排队→执行→等输入/授权→完成/失败/已停/异常中断；失败节点有日志与重试范围。
验收：进程中断不永远转圈。

#### 配置错误
引擎缺失/模型不可用/目录不可写/技能过大/运行阻止更新分别说明；保存失败保留编辑。
验收：错误有可执行下一步。

### 交互与动效

#### 流式稳定
输出增量追加，向上阅读不强制跟随，提供回到底部；节点推进 200ms，不全体脉冲。
验收：长日志可读可复制。

#### 即时状态
停止/失败/授权立即可见；面板轻淡入；光斑不遮代码文字。
验收：减少动态效果仍知道进度。

### 内容与边界情况

#### 真实产物
已落盘/部分/生成中/不存在分开；打开只用允许路径；长文件名可复制。
验收：中断不丢弃部分成果。

#### 安全边界
并发/取消/关闭/导入/更新保留保护；凭据遮罩，日志不回显密钥；UI 不改沙箱/目录校验。
验收：安全逻辑与旧版相同。

### 可用性与无障碍

#### 编辑替代
重排提供上移/下移代替拖拽；日志可选复制，模型可键盘选。
验收：编辑不只依赖鼠标。

#### 进度可读
当前节点有文字；流式输出不逐 token 播报；退出确认安全焦点/Esc 取消。
验收：授权状态可被及时发现。

### 重点验收场景
- 无引擎
- 目录不可写
- 授权检查点
- 中断与部分成果
- 运行期间更新
- 长日志与减弱动效
