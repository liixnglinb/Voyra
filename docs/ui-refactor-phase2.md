## 边界探索

- 连续改筛选与快速切页，检查旧响应不覆盖新结果、焦点不被重复初始化。
- 上次有效结果＋服务中断，检查旧内容保留且状态明确。
- 未知价格、合法零价格与套餐同时出现时，不更改后台统计口径。
- 长文件路径、跨分页全选及部分失败清单，不把仅已加载容量误称为全量。
- 减少动态效果与手机布局，不隐藏主动作或关键警告。

## 测试结果

- AI 轨迹：构建及 62 项原有测试通过；覆盖档案/成果筛选、返回恢复、命令无结果/定位、首次与后续采集失败、未知日期及精确图表明细。

- 磁盘清理：renderer 构建通过；默认取消焦点、Esc 恢复、完整路径审阅、44px 虚拟行、部分失败报告、读取重试和未知进度通过。容量标注统一为 KiB/MiB/GiB/TiB，API 字段保持兼容。
- 学习通：TypeScript 编译、原有 UI 校验及 27 项测试通过。连接失败、账号空态、监听状态回退、弹窗焦点通过；390px 下六个导航入口完整可见。二维码动作合并到固定头部，避免浮动按钮遮挡课程状态。

浏览器回归使用已构建的前端与内存模拟服务。清理报告验证只返回一次模拟删除结果，不访问任何真实文件；没有运行真实签到或智能体任务。桌面和 1024×768 小窗口检查无整页横向溢出，密集文件表在自身容器内横向滚动。
