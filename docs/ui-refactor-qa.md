# Voyra UI 重构验收清单

日期：2026-10-02。只使用本地开发与安全设计示例，不调用真实签到、文件删除或智能体执行。

## 网站

- 产品 11 张、应用 7 张卡片：名称、说明、链接、键盘焦点和 CTA 完整；Skills、关于我、交流卡同材质。
- 五个分类：鼠标及键盘切换、URL 状态、返回；下载卡保持桌面新标签/手机就地跳转。
- 光斑、轻倾斜、入场、离屏暂停；运行时减少动态效果即时生效。
- 七个下载页：卡片样式、关键下载入口和动态版本脚本保持可用。
- 1440×1000、1280×800、768×1024、390×844、320×740 无整页横向溢出；核心内容无遮挡。

## 软件 UI 规范页

- 平台通用与五款产品切换；七个维度均有规则与验收。
- 搜索有结果/无结果/清空；状态矩阵可横滚；数据不被截断。
- 复制成功/权限失败回退；导出 Markdown 包含公共基线与所选产品，不含私人数据。
- 预览深浅切换；默认、加载、禁用、成功、失败均可读；演示加载后反馈。
- 安全确认示例：焦点进入、取消/确认、Esc 关闭、焦点恢复；不执行文件操作。

## 五款软件

- 样式资源同源校验；React 构建、签到 TypeScript 检查、静态脚本/样式解析。
- AI 轨迹：工作台/档案/设置、深浅主题、窄窗口。
- Token 统计：总览/模型/设置、空数据、计量色与数字。
- 磁盘清理：未扫描/设置、深浅主题、清理禁用态；不进行真实删除。
- 学习通：无账号/示例课程/设置、手机、监听状态；不发起真实签到。
- 织流：主台/设置、深浅主题、无引擎与空产物；不启动真实任务。

## 探索性检查

- 连续切换分类/规范维度 10 次，确认不丢状态、不重复绑定事件。
- 移动端和减少动态效果下打开/关闭确认，检查滚动、焦点和布局。
- 超长检索、无结果、下载导出以及被拒绝的剪贴板权限。

## 验收结果

第二轮补充（2026-10-03）：主要页面的 20 项浏览器回归全绿，包含采集/读取失败、筛选恢复、未知价格/日期/进度、清理部分结果、焦点及移动导航。详细清单、命令与边界见 ui-refactor-phase2.md。

本轮记录：网站构建及 9 项数据/路由/导出回归检查通过；AI 轨迹、磁盘清理 renderer 构建通过；签到重新编译后的 UI 校验通过。

浏览器已覆盖五个网站断点、七个下载页桌面/手机、42 个对象/维度组合、搜索边界、复制与导出、剪贴板权限失败、预览五种状态、确认焦点、分类键盘切换、下载真实跳转和减少动态效果。没有在这些已检查的页面状态中发现未捕获脚本错误或整页横向溢出。

软件的主界面使用空态或明确标注的测试数据预览。逐页所有业务状态、原生窗口/DPI、真实清理、账号登录与安装包发布尚未验收。详细范围见 `ui-refactor-handoff.md`。
