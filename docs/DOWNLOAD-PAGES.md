# 五个应用的下载页

范围：`/checkin/`、`/local-toolbox/`、`/billtrace/`、`/token-monitor/`、`/ai-chronicle/`。

这轮修改只涉及网站中的产品介绍与下载界面。应用本体、后端、主站卡片的位置和尺寸不变。

页面统一为应用介绍与预览、三项核心能力、三步上手、下载安装、常见问题和相关应用。配色与图标按应用保留，Token Monitor 使用已有真实截图，其余预览注明示意数据。手机上按同样的信息顺序排为单列。

## 维护位置

- `build-tools/download-products.mjs`：五个应用的内容、静态版本兜底、下载文件规则及平台要求。
- `build-tools/build-download-pages.mjs`：生成静态 HTML，运行 `npm run build:downloads`。
- `public/design-system/download-pages.css`：共享视觉与响应式布局。
- `public/design-system/download-pages.js`：版本读取、线路选择、复制、截图切换和错误兜底。
- `public/design-system/download-motion.css`、`download-motion.js`：五种产品演示、入场、滚动与指针交互；原生 CSS / Web Animations，无新增运行依赖。
- `public/<应用>/index.html`：可直接部署的完整静态页面，关闭 JavaScript 时仍有功能介绍和有效下载链接。

生成步骤不挂入每次生产构建，避免覆盖其他发布流程同步进 HTML 的版本信息。修改页面内容后手动重新生成；更新静态发布兜底时，同时更新产品数据。

## 动效

签到助手以扫描光带和课程响应串起签到流程；磁盘助手保留容量占比，用独立轨道显示扫描；账迹将通知、账目和预算条的节奏联动；Token Monitor 在真实截图旁显示采集、归一与统计的数据流，切换截图时平滑过渡；AI 轨迹沿时间线逐条点亮，再将结果落到摘要标记。演示中的数值不冒充实时数据。

共享动效包括首屏分层入场、滚动入场、预览随指针轻微倾斜、卡片光照与按钮反馈。预览右上角可暂停，偏好在当前浏览器会话的五页之间保留。预览离开视野、页面进入后台时停止循环；用户启用系统“减少动态效果”后，立即取消入场、停止循环并显示完整静态内容。关闭 JavaScript 时仍显示所有正文、截图和有效下载入口。触屏不运行指针倾斜。

## 保留的下载能力

安装包仍来自对应项目的 GitHub Releases，支持国内镜像、备用镜像和直连；磁盘清理助手保留原有 ghproxy.net 备用线路。AI 轨迹与 Token Monitor 均提供安装版和便携版，账迹为 Android APK，签到助手保留完整介绍页链接。

AI 轨迹、Token Monitor、账迹优先读取现有站内版本代理，其次尝试 GitHub API 与镜像。账迹的固定 `latest` tag 从发布标题或代理字段解析版本，不能把 tag 字面值当版本号。大小为 0 时显示“大小以发布页为准”，不输出虚构体积。只有匹配到有效主安装资产才应用新的发布版本；无可用元数据时保留原静态链接并说明版本未刷新。

Token Monitor 与账迹支持自动选择线路，也可手动覆盖。探测限制读取字节数，有超时、缓存和后台中止；只有成功读取非 HTML 响应才参与比较。复制链接直接复制完整地址，不拼接站点 origin。SHA-256 仅在版本代理确实提供合法校验值时展示。

## 验证

先运行 `npm run build`，再运行 `npm run test:downloads`。浏览器测试使用构建产物和生产 CSP，只模拟公开发布元数据与下载探测，不下载真实安装包或运行应用。

覆盖 1440、1024、768、390、320px 共 25 个页面布局；检查图片、下载路径、源切换及持久化、复制内容、FAQ、截图页签键盘操作、元数据不可用和 0 字节信息兜底。截图与报告保存在忽略目录 `output/playwright/download-pages/`。原有 `npm run test:ui` 也需通过。

同一浏览器验证还覆盖 1440、390、320px 的 15 个动态页面：检查五种专属动画实际推进、暂停/恢复、暂停偏好保留、移出视野停止、运行时切换减少动态效果、指针倾斜和无横向溢出；另检查五页无 JavaScript 时的正文、下载及原生 FAQ。`motion-*.png` 为动画运行中的画面；截图中的版本和元数据来自测试夹具。
