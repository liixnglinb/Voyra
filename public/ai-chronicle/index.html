WHAT IT DOES

从活动记录到工作档案

不是简单统计软件开了多久，而是把会话、任务、项目与文件产出连成可追溯的证据链。

01 / DAILY

每日 AI 日报

自动归纳今天完成了什么、进展如何、生成了哪些文件，并标出每条结论的来源可信度。

02 / HISTORY

历史工作回看

通过月历和每日档案回看过去的任务、投入时长与成果，不再依赖零散记忆。

03 / TASKS

任务与项目账本

把不同软件的会话归入同一项目，显示任务状态、完成度、耗时、工具与结果。

04 / INSIGHTS

趋势分析

查看 AI 活跃时长、Token、软件贡献和长期节奏，理解自己的高效时段。

05 / LOCAL

默认本地优先

原文和任务默认保存在本机；敏感信息脱敏、云端摘要和排除目录均可独立控制。

06 / UPDATE

GitHub 自动更新

桌面端自动识别 GitHub Releases 新版本，在应用内下载并安装，无需重新访问下载页。
