会话、代码或文件会被上传吗？+

不会联网上传会话、代码或文件内容。日志与数据库只在本机做只读解析，统计和工作档案留在自己的电脑里。

与 Token Monitor 有什么不同？+

Token Monitor 主要回答用量与估算成本。AI 轨迹关注任务、会话、项目、产出和工作续接；二者可以按需搭配使用。

安装版和便携版有什么区别？+

安装版提供桌面与开始菜单入口，支持应用内更新，日常使用推荐。便携版直接运行，新版本需要手动下载替换。

支持 macOS 或 Linux 吗？+

当前提供 Windows 10 / 11 x64 版本。其他平台的发布情况，以项目 Releases 为准。
