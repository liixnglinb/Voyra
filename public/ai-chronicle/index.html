FAQ

几个常见问题

我的会话内容会被上传吗？

不会。AI 轨迹只在本机读取各软件的本地日志与数据库做只读解析，不联网上传任何会话、代码或文件内容。所有统计都在你自己的电脑上完成。

支持 macOS 或 Linux 吗？

目前仅支持 Windows 10/11 x64。macOS 与 Linux 版本在规划中，可以关注 GitHub Releases 获取发布动态。

安装版和便携版有什么区别？

安装版支持应用内自动更新（直连 / 镜像自动择优），日常使用推荐安装版。便携版不写系统，随时可删，但需要手动下载新版本替换。

如果某个 AI 软件没有被识别怎么办？

打开应用内的「数据源」页，查看每个源的扫描状态；新软件的数据源适配会随版本持续增加，也可以在 GitHub 仓库提 Issue 反馈。
