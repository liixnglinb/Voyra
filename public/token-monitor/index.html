02

按真实单价计价

内置 1.2 万条模型价格。套餐/订阅制的模型只记用量、不计金额并单独标注；走 API 而价表缺价的如实标「价格未知」—— 两种情况分开说，绝不假装算得出。

03

缓存命中率

区分未命中输入、缓存写入、缓存命中与输出四类 token，一眼看出省钱空间。

04

Agent 排行与下钻

按消耗量排名，点开任一 Agent 即可看到它下面每个模型用了多少、请求了几次。

05

对话级明细

把鼠标停在柱状图上，就能看到那一天的消耗分别来自哪些对话。

06

装完就不用管

内置更新器，发现新版本一键下载替换重启；安装版与便携版都支持。

怎么选

安装版 装到当前用户目录（无需管理员权限），带开始菜单与桌面快捷方式，可在「应用和功能」卸载 · 便携版 压缩包里就是单个 TokenMonitor.exe，解压双击即运行，不写注册表、可放 U 盘 · 单文件版 同一个裸 exe，也是更新器下载的对象。

三者内置同一个更新器 —— 装完之后，后续更新都在软件里点「检查更新」完成，不必重新下载安装。

macOS / Linux 为什么还没有 当前打包链是 PyInstaller + Inno Setup，只产出 Windows 产物；跨平台需要各自的原生打包与签名流程，做完会在这里放出真实下载链接，不会先挂一个点不动的地址。
