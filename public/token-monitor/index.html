03

工作原理

四步 · 全程只读
  • 01
    发现

    按注册表登记的 81 条路径逐个探测本机日志目录，认不出的文件不猜、不计。

  • 02
    解析

    只取用量字段：模型、输入 / 输出 / 缓存读取与写入、时间。不保存对话原文。

  • 03
    计价

    内置模型价目表（可用 custom-pricing.json 覆盖），按每条记录自己的模型单价折算金额。

  • 04
    呈现

    增量缓存（本次命中 10 / 重扫 5 / 零结果判定 13），面板只读快照，滚动筛选不动磁盘。

05

隐私边界

无账号 · 无上传 · 无服务

它会读

  • 路径注册表登记的 81 条来源路径，逐条探测是否存在日志目录
  • 字段用量字段：模型名、输入 / 输出 / 缓存读写 token 数、时间戳
  • 缓存本机缓存目录里的扫描快照，用于下次增量比对

它不会

  • 正文不保存对话原文；面板与 CSV 导出里都只有用量字段
  • 网络不上传任何数据；只有「检查更新」会联网，且只请求版本信息
  • 系统不写系统目录、不加常驻服务；只装到当前用户目录，卸载即清

口径说明

页面数字与面板一致
金额主显人民币

按 cost_usd × 7.1 折算，副行给出美元与汇率，与面板 KPI 完全一致。

套餐不计费

订阅制模型只记用量不计金额，本机为 2.72 B tokens；面板里同样标注「套餐不计费」。

未计价

模型不在价目表内时，用量照记、金额留空——本机 658.2 M tokens（占 9.2%），实际成本会更高。

缓存命中率

命中读取 ÷（输入 + 缓存写入 + 缓存读取），口径与面板相同；本机 71.4%。

07

常见问题

首次运行被 SmartScreen 拦下

安装包没买代码签名证书，Windows 会提示「Windows 已保护你的电脑」。点「更多信息 → 仍要运行」即可；安装包与更新包的 SHA-256 都随发布一起公开，可自行核对。

统计不到我常用的工具

面板侧栏有「未计入」分组，会写清每个工具为什么没进来：本地日志加密（如 Cursor、TRAE）或用量只存在服务端。只要该工具在本机落了可解析的日志，就会自动计入。

软件要联网吗

面板本身离线可用：所有数字都来自本机日志。只有「检查更新」会联网，且走镜像测速择优。

会不会拖慢电脑

扫描是增量的：命中缓存的目录只比对时间戳，只重扫变化的文件。面板读的是缓存快照，切页不触发重扫。

怎么卸载

设置 → 应用 → 已安装的应用 → Token Monitor → 卸载；装的时候没有写系统目录，也没有常驻服务。
