FAQ

常见问题

支持什么操作系统？

目前仅支持 Windows 10 / 11 的 64 位系统。下载后双击安装包即可安装，装到当前用户目录，无需管理员权限、不会弹 UAC。macOS 版本暂未提供。

需要会编程吗？零基础能用吗？

不需要手写代码。你只需填入赛题（文字 / PDF / 图片均可）、选好模型与模板，点击开始，建模、写代码、跑结果、画图、写论文都由流水线自动完成。具备建模基础能让你更好地审阅和修改中间产物。

下载为什么需要授权码？

ModelFlow 为小范围授权分发软件。点击「下载 Windows 版」会弹出一个小窗口，输入你获得的 5 位授权码即可解锁下载；该授权码同时用于软件首次启动时的激活（一码一机）。请向开发者索取。

AI 模型要自己准备吗？怎么计费？

软件本身不售卖模型额度。你在设置中填入自己的 API Key（或接入本地 CLI 模型）即可运行，费用直接交给你选择的模型服务商，软件不经手、不抽成。

装了新版本，数据和授权会丢吗？

不会。无论是应用内在线更新，还是下载新安装包覆盖安装，授权、工作区、模型配置与所有产物都会原样保留。

如何确认安装包没被篡改？

更新清单 latest.json 公布了安装包的 SHA-256 摘要。下载后可在文件目录执行 certutil -hashfile 文件名 SHA256 比对，一致即完整未被篡改；软件内自动更新也会强制校验。
