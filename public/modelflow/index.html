Capabilities

它不做代写，它管流程

正文一律由你本机已登录的 Claude Code 或 Codex CLI 产出。Loom 负责把任务拆开、把提示词规范喂到位、盯着每一步的产物、在需要确认的地方停下来等你。

可视化编排流程

增删步骤、拖顺序，每步绑定技能、产物文件名、角色（执行 / 复核 / 编辑）、引擎与模型，可设检查点暂停等确认。改完即存，不用重装模板。

技能库

每步的提示词规范独立成技能，可新建、编辑、另存副本，也支持导入标准 skill 包（zip / SKILL.md）。内置一套数模全流程技能，也能整个恢复出厂。

实时流式运行

SSE 把每一步的工具调用、输出与耗时逐行推给你；右上角进程卡对应每一步状态，点一行直接跳到那一步的转录。

工作区实时反馈

智能体写到哪，面板就列到哪：markdown 就地渲染、图片与 PDF 内联预览、刚写入的文件高亮。不用等跑完再去文件夹里翻。

对话式局部修订

结果不满意不用整条重跑 —— 指着某一步说怎么改，只重写那一步，其余产物原样保留。

流程导入导出

一条流程 = 一个 JSON 文件。可分享、可备份、可导回；撞名会问你另存为副本，不会静默覆盖。

How it works

四步上手

01

装好一个智能体 CLI 并登录

Claude Code（claude）或 Codex CLI（codex）任一即可。Loom 在设置页自动探测本机可用的引擎，两个都装了就每步都能选。

02

装 Loom，打开就是工作台

安装包约 36 MB，装在你自己的用户目录下，不需要管理员权限。双击启动后开一个独立窗口（打不开原生窗口时会自动退回默认浏览器）。

03

挑一条流程，或自己编一条

内置「通用全自动工作流」和「轻量三步流」，也可以复制一份改。每步绑定哪个技能、产出什么文件、要不要停下来等你确认，都是明摆着可编辑的。

04

下任务，看它跑

写清任务说明就能开跑。转录区实时输出，进程卡显示走到第几步，工作区面板列出正在写的文件；跑完对着任意一步提修改要求即可。

Requirements

跑起来需要什么

Windows 10 / 11 x64macOS / Linux 暂未提供安装包（源码可跑）。
Claude Code 或 Codex CLI已安装并已登录。这是内容产出的唯一通道。
约 200 MB 磁盘程序本体 + 数据目录。产物多大取决于你的任务。
可选：API 预设把端点/密钥/模型注入给 CLI，用于换模型或走中转。

一条硬规则：Loom 自己不直连任何大模型接口生成正文。设置里的 API 预设只用于配置 CLI 的端点与模型，正文只能出自你本机已登录的 Claude Code / Codex CLI。你的提示词、流程和产物都留在本机，软件没有账号体系，也没有埋点。

FAQ

常见问题

为什么还要装 Claude Code / Codex CLI？+

因为正文由它们生成。它们各自带着你自己的登录态或密钥与模型通信，Loom 负责流程编排、提示词规范、产物落盘和过程可视化。这样换模型、走中转、调额度都在 CLI 那边，不会被软件锁死在某一家。

我的数据和产物存在哪？+

安装目录下的 data\：SQLite 数据库、每次运行的工作区（data\workspaces\run-xxx\）、你自建的技能、导出件都在里面。设置页「本地目录」可以直接打开它们。

卸载会删掉我的流程吗？+

不会。卸载器刻意保留 data\ 整个目录，重装后自动继续读取。要彻底清掉自己的数据，需要你自己删那个文件夹。

怎么更新？+

左下角会出现「更新」胶囊 —— 软件启动后自动读一次版本清单，有新版本才出现。点一下开始下载，进度实时显示，下载完成后确认即静默安装并退出；有任务在跑或停在检查点时会先弹提示。

跑一次大概多久？+

取决于步骤数和智能体本身。内置七步全流程在单题上通常是几十分钟量级；每步耗时、工具调用次数、累计费用都会记在运行记录里，设置页「使用统计」有汇总。

有 macOS 版吗？+

安装包暂时只有 Windows。后端是 FastAPI，macOS / Linux 可以用源码运行：pip install -r requirements.txt && python run.py。

源码在哪？+

GitHub：liixnglinb/Loom。含 122 条回归测试，界面文案中英双语，无框架无构建步骤。
