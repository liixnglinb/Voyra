Capabilities

它不做代写，它管流程

正文一律由你本机已登录的 Claude Code 或 Codex CLI 产出。Loom 负责把任务拆开、把提示词规范喂到位、盯着每一步的产物、在需要确认的地方停下来等你。

可视化编排流程

增删步骤、上下移调整顺序，每步绑定技能、产物文件名、角色（执行 / 复核 / 编辑）、引擎与模型，可设检查点暂停等确认。改完即存，流程本身就是一条可编辑的清单。

流程 = 一个可编辑的 JSON

技能库

Pipeline

七个环节，
三段式接力

下面这条「需求 → 拆解 → 备料 → 逐项执行 → 复核 → 修订 → 交付」是编排出来的一种典型形态：任意一段都能改成自己的样子，每一步加载你指定的技能作为方法内核，产物逐级往下传，环环自检。

STAGE 01

理解与建模

把开放题变成可计算的问题：界定范围、拆出子问题、确定方法并跑出第一版结果。

  • 01需求解析检查点REQUIREMENTS.md
  • 02方案拆解检查点PLAN.md
  • 03信息收集FINDINGS.md

角色：执行 · 产物逐级传给下一段

STAGE 02

执行与复核

按拆解逐项落地，再以复核视角独立审一遍 —— 写的人和查的人不是同一步。

  • 04逐项执行检查点EXECUTION.md
  • 05自检复核REVIEW.md

角色：执行 → 复核 · 复核步骤由 reviewer 角色独立跑

STAGE 03

打磨与交付

按复核意见改稿，最后把分散产物整合成一份能直接交出去的东西。

  • 06修订打磨FINAL.md
  • 07交付整合DELIVERABLE.md

角色：编辑 → 执行 · 只改被打回的那一步

How it works

四步上手

01

装好一个智能体 CLI 并登录

Claude Code（claude）或 Codex CLI（codex）任一即可。Loom 在设置页自动探测本机可用的引擎，两个都装了就每步都能选。

02

装 Loom，打开就是工作台

安装包约 36.2 MB，装在你自己的用户目录下，不需要管理员权限。双击启动后开一个独立窗口（打不开原生窗口时会自动退回默认浏览器）。

03

编一条你自己的流程

从零加步骤，或者导入别人分享的流程 JSON 改。每步绑定哪个技能、产出什么文件、要不要停下来等你确认，都是明摆着可编辑的 —— 软件不预设该怎么干活。

04

下任务，看它跑

写清任务说明就能开跑。转录区实时输出，进程卡显示走到第几步，工作区面板列出正在写的文件；跑完对着任意一步提修改要求即可。

Claude Code 或 Codex CLI已安装并已登录。这是内容产出的唯一通道。

一条硬规则：Loom 自己不直连任何大模型接口生成正文。设置里的 API 预设只用于配置 CLI 的端点与模型，正文只能出自你本机已登录的 Claude Code / Codex CLI。你的提示词、流程和产物都留在本机，软件没有账号体系，也没有埋点。

不是跑在我们的服务器上

没有账号体系

不注册、不登录、不联网激活。装完打开就能建流程跑任务。

没有埋点

唯一的对外请求是检查更新时读一次版本清单，其余网络流量都来自你自己的 CLI。

数据留在 data\

FAQ

常见问题

为什么还要装 Claude Code / Codex CLI？+

因为正文由它们生成。它们各自带着你自己的登录态或密钥与模型通信，Loom 负责流程编排、提示词规范、产物落盘和过程可视化。这样换模型、走中转、调额度都在 CLI 那边，不会被软件锁死在某一家。

我的数据和产物存在哪？+

安装目录下的 data\：SQLite 数据库、每次运行的工作区（data\workspaces\run-xxx\）、你自建的技能、导出件都在里面。设置页「本地目录」可以直接打开它们。

卸载会删掉我的流程吗？+

不会。卸载器刻意保留 data\ 整个目录，重装后自动继续读取。要彻底清掉自己的数据，需要你自己删那个文件夹。

怎么更新？+

左下角会出现「更新」胶囊 —— 软件启动后自动读一次版本清单，有新版本才出现。点一下开始下载，进度实时显示，下载完成后确认即静默安装并退出；有任务在跑或停在检查点时会先弹提示。

检查点是做什么的？+

给关键步骤加检查点后，流程跑到那里会停下来等你看产物、给意见，确认了才往下走。哪几步该停由你在编排时决定 —— 通常是那种走偏了后面全白跑的步骤，比如需求界定和方案拆解。

跑一次大概多久？+

取决于你编了几步、每步的智能体干什么活。几十分钟的量级很常见；每步耗时、工具调用次数、累计 token 都会记在运行记录里，设置页「使用统计」有汇总。

有 macOS 版吗？+

安装包暂时只有 Windows。后端是 FastAPI，macOS / Linux 可以用源码运行：pip install -r requirements.txt && python run.py。

源码在哪？+

GitHub：liixnglinb/Loom。带一整套回归测试，其中一部分专门看守静态资产契约 —— 配色令牌只许在 token 块里出现、圆角字号只能取刻度上的值、中英两套文案键位必须对齐、图标 ico 的档位和小尺寸五官都有用例钉着。界面文案中英双语，前端无框架无构建步骤。
