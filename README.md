## ✨ 特性 / Features

- 🧑‍🎨 个人介绍与作品集展示
- 📦 项目卡片与经历时间线
- 📱 响应式设计，桌面 / 移动端适配

## 🧰 技术栈 / Tech Stack

- **构建工具**：[Vite](https://vitejs.dev/)
- **前端**：JavaScript + [Tailwind CSS](https://tailwindcss.com/)
- **服务端**：Cloudflare Pages Functions（`functions/`）与数据库迁移（`migrations/`）

## 🚀 本地开发 / Getting Started

```bash
# 克隆项目
git clone https://github.com/liixnglinb/Voyra.git
cd Voyra

# 安装依赖
npm install

# 启动开发服务器
npm run dev

# 构建生产版本
npm run build
```

> 💡 环境变量请参考 `.env.example`，复制为 `.env` 后按需填写。
